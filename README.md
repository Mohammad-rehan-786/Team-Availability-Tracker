# TeamPulse – Team Availability Tracker

A modern, responsive team availability dashboard built with React and Vite. TeamPulse helps users manage team members and track their availability through a clean and interactive interface.

## Features

- **Dashboard Overview** – View total, available, and unavailable team members.
- **Availability Toggle** – Update a member's availability instantly.
- **Team Management** – Add, edit, and delete team members.
- **Search & Filter** – Find members by name, email, role, or department.
- **Analytics** – View team availability statistics.
- **Local Storage** – Automatically saves data in the browser.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.

## Tech Stack

- React
- Vite
- JavaScript
- CSS3
- Lucide React
- Browser Local Storage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mohammad-rehan-786/team-availability-tracker.git
```

Navigate to the project folder:

```bash
cd team-availability-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Data Storage

TeamPulse uses browser Local Storage to save team member information.

**Note:** Data is stored locally in the browser. It does not synchronize across different devices or users because this project does not use a backend database.

## Deployment

The project is configured for deployment using GitHub Pages.

```bash
npm run deploy
```
